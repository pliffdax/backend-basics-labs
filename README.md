# Backend Basics Labs

Репозиторій містить лабораторні роботи з дисципліни PHP/MySQL та NodeJS (MongoDB, GraphQL).

## Лабораторні роботи

- **Лабораторна робота №1** — PHP & MySQL: установка (XAMPP/Denver), створення БД, просте виведення даних  
  Гілка: [labs/lab1](https://github.com/pliffdax/backend-basics-labs/tree/labs/lab1)

- **Лабораторна робота №2** — PHP & MySQL: введення, редагування, видалення даних, сортування  
  Гілка: [labs/lab2](https://github.com/pliffdax/backend-basics-labs/tree/labs/lab2)

- **Лабораторна робота №3** — PHP & MySQL: сторінка статистики та пошук по сайту (keyword/pattern/діапазон)  
  Гілка: [labs/lab3](https://github.com/pliffdax/backend-basics-labs/tree/labs/lab3)

- **Лабораторна робота №4** — NodeJS (Express): роутинг + шаблонізація, застосунок погоди (/weather/{city})  
  Статус: в процесі виконання

- **Лабораторна робота №5** — NodeJS + MongoDB: CRUD + роутінг + вивід JSON  
  Статус: в процесі виконання

- **Лабораторна робота №6** — GraphQL: Schema (SDL) + Resolvers + Query/Mutation + Postman  
  Статус: в процесі виконання
